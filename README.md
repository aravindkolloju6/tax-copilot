Overview

Tax Copilot is an AI-powered assistant that helps users understand taxation concepts, calculate tax information, and receive intelligent guidance using natural language.

The application integrates Google AI Studio (Gemini API) to deliver smart tax-related insights and responses. It is designed as an educational and practical tool to simplify complex tax topics for individuals.

This project demonstrates how AI can be integrated with modern web technologies to build intelligent financial tools.

Prerequisites

Before running the project, make sure you have:

Node.js installed

npm installed

Gemini API key from Google AI Studio

Installation

Clone the repository

git clone https://github.com/your-username/tax-copilot.git

Navigate to the project directory

cd tax-copilot

Install dependencies

npm install
Configure Environment Variables

Create a .env.local file in the root directory and add your Gemini API key.

GEMINI_API_KEY=your_gemini_api_key_here
Run the Application

Start the development server:

npm run dev

The application will run locally and open in your browser.
